# Astrix Code Client

React portfolio website built with Vite.

## Commands

```powershell
npm install
npm run dev
npm run build
npm run lint
```

## Source folders

- `src/pages/` — route pages.
- `src/sections/` — reusable website sections.
- `src/components/` — shared components.
- `src/data/` — site content and project data.
- `src/styles/` — theme and global styles.
- `public/TechIcons/optimized/` — technology icons used by the site.
